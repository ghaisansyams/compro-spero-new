Portfolio / Gameway

Game transactions. A connected platform.

A web application and API project for game-voucher workflows, designed for merchants, resellers, and developers in Indonesia.

All workVisit gameway.id

01 / Product context

One interface.
An API behind it.

The public website introduces Gameway as a game top-up and voucher API for Indonesian businesses. This overview focuses on the Kiosgamer voucher workflows found in the implementation, rather than the wider roadmap.

The application pairs a web interface with a separate backend API. The inspected frontend marks game top-ups as coming soon and disables self-service API-key management; neither is presented here as an available feature.

02 / Inside the implementation

The working parts.

Transaction history

The web interface includes status and provider filters, with expandable transaction details. The backend retrieves transaction records for the signed-in account.

Bulk voucher workflows

The implementation accepts batches of voucher codes and provides periodically refreshed progress with per-voucher results. Backend logic checks the Kiosgamer session before queuing a batch.

A separate application and API

Next.js, React, TypeScript, and Tailwind CSS form the web application. The backend uses Express with Prisma and PostgreSQL for data access.

About this overview

Product context is based on the public website. Technical descriptions reflect the inspected implementation, not a production audit or a claim about transaction performance.
