Portofolio / Gameway

Transaksi game. Satu platform yang terhubung.

Project aplikasi web dan API buat alur voucher game, dirancang untuk merchant, reseller, dan developer di Indonesia.

Semua hasil kerjaKunjungi gameway.id

01 / Konteks produk

Satu interface.
Satu API di baliknya.

Website publiknya mengenalkan Gameway sebagai API top-up dan voucher game buat bisnis di Indonesia. Ikhtisar ini fokus ke alur voucher Kiosgamer yang ada di implementasi, bukan roadmap yang lebih luas.

Aplikasinya menggabungkan web interface dengan backend API terpisah. Di frontend yang kami review, fitur top-up game ditandai coming soon dan self-service API key management dimatikan; keduanya tidak disajikan di sini sebagai fitur yang sudah jalan.

02 / Isi implementasi

Part-part yang bekerja.

Riwayat transaksi

Di web interface ada filter status dan provider, dengan detail transaksi yang bisa dibuka. Backend mengambil catatan transaksi untuk akun yang sedang login.

Voucher massal

Implementasi menerima banyak kode voucher sekaligus dan menampilkan progress berkala plus hasil per voucher. Logic backend cek sesi Kiosgamer sebelum masuk batch queue.

Aplikasi dan API terpisah

Next.js, React, TypeScript, dan Tailwind CSS membentuk web app-nya. Backend pakai Express dengan Prisma dan PostgreSQL buat akses data.

Tentang ikhtisar ini

Konteks produk diambil dari website publik. Deskripsi teknis mencerminkan implementasi yang kami review, bukan audit produksi atau klaim soal performa transaksi.
